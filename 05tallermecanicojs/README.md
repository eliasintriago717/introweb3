# Sistema de Gestión - AutoTech Taller Automotriz

Este es un sistema web para la gestión de vehículos en un taller mecánico, desarrollado aplicando estándares de estructuración HTML5, diseño responsivo con CSS3 y manipulación dinámica del DOM con JavaScript.

## 🚀 Requisitos del Sistema
- **Páginas HTML:** Contiene 4 páginas interconectadas (`index.html`, `servicios.html`, `nosotros.html`, `vehiculos.html`).
- **Módulo Principal (CRUD):** Gestión completa de vehículos (Registrar, Editar, Eliminar y Consultar).
- **Herramientas:** Búsqueda en tiempo real por término y ordenamiento por kilometraje.
- **Estadísticas:** 4 contadores en tiempo real que resumen el estado del taller.

## 🌟 Funcionalidades Adicionales
1. **Filtrado dinámico por Estado:** Permite segmentar el listado de vehículos según si están "Ingresados", "En Reparación" o "Listos".
2. **Exportación de Reportes:** Genera y descarga automáticamente un archivo `.csv` compatible con Excel con todos los registros en memoria.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructuración semántica.
- **CSS3:** Flexbox, Grid, Variables CSS y diseño adaptable.
- **JavaScript (Vanilla):** Lógica del negocio, manipulación de arreglos y validación de formularios sin frameworks.

## 📂 Instrucciones de Ejecución
1. Descargar o clonar la carpeta del proyecto.
2. Abrir el archivo `index.html` en cualquier navegador web (Chrome, Firefox, Edge).
3. Navegar a la pestaña **Vehículo** para probar las funciones completas de administración.
